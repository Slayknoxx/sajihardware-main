CONFIGURATION REQUIRED
═══════════════════════════════════════════════════════════════════════

BEFORE USING THE SYSTEM:

Edit /config.php and update these constants:

1. ETIMS_ENABLED = true
   Purpose: Enable/disable ETIMS processing
   Current: true (enabled by default)

2. KRA_PIN = 'A000123456X'
   ⚠️ UPDATE REQUIRED
   Your 11-digit KRA PIN
   Format: Letter + 9 digits + Letter
   Example: A000123456X

3. VSCU_SERIAL = 'VSCU_SERIAL_NUMBER'
   ⚠️ UPDATE REQUIRED
   Your VSCU device serial number
   From: Hardware device or KRA documentation

4. VSCU_VERIFICATION_KEY = 'your-key'
   ⚠️ UPDATE REQUIRED
   Encryption key from KRA
   Length: 256 characters recommended
   Keep: CONFIDENTIAL - like a password

5. VSCU_DEVICE_ID = 'device-unique-id'
   ⚠️ UPDATE REQUIRED
   Unique ID for this POS terminal
   Format: location-number (e.g., webuye-001)
   Use: Consistently for this terminal

6. ETIMS_SANDBOX = false
   Testing: Set to true for sandbox
   Production: Set to false

7. ENABLE_RECEIPT_ENCRYPTION = true
   Secure storage of receipts

8. ENABLE_RECEIPT_SIGNING = true
   Digital signature on receipts

MONTHLY KRA COMPLIANCE
═══════════════════════════════════════════════════════════════════════

GENERATE REPORT:
SELECT 
  strftime('%Y-%m', created_at) as month,
  COUNT(*) as transactions,
  SUM(total) as gross_sales,
  SUM(tax) as total_vat
FROM sales 
WHERE status = 'COMPLETED'
GROUP BY month;

- Login: itax.kra.go.ke
- Select: Monthly VAT Return
- Upload: Generated report
