VAT CALCULATION FORMULA
=======================

Given total amount (inclusive of VAT):
VAT = Total / 1.16 * 0.16
Base = Total - VAT

Example:
Total Amount: 1,160 KES
VAT = 1,160 / 1.16 * 0.16 = 160 KES
Base = 1,160 - 160 = 1,000 KES

System shows:
- Subtotal: 1,000
- VAT (16%): 160
- Total: 1,160


USEFUL SQL QUERIES
==================

See today's VAT:
SELECT 
  DATE(created_at) as date,
  COUNT(*) as transactions,
  SUM(total) as total_amount,
  SUM(tax) as total_vat
FROM sales
WHERE status = 'COMPLETED'
  AND DATE(created_at) = DATE('now')
GROUP BY DATE(created_at);

See receipts with QR codes:
SELECT receipt_no, etims_unique_id, created_at
FROM sales
WHERE etims_qr_code IS NOT NULL
ORDER BY created_at DESC
LIMIT 20;

Check for failed ETIMS:
SELECT receipt_no, etims_error_message, created_at
FROM sales
WHERE etims_status = 'FAILED'
ORDER BY created_at DESC;

Monthly VAT report:
SELECT 
  strftime('%Y-%m', created_at) as month,
  COUNT(*) as sales,
  SUM(total) as gross,
  SUM(tax) as vat_collected
FROM sales
WHERE status = 'COMPLETED'
GROUP BY month
ORDER BY month DESC;

TROUBLESHOOTING QUICK FIX
=========================

Issue: QR code not showing
Fix: Check internet connection, verify config values

Issue: VAT seems wrong
Fix: Remember VAT is INCLUSIVE in total, not added separately

Issue: ETIMS status is FAILED
Fix: Check etims_error_message in database, verify KRA_PIN format

Issue: Receipt won't print
Fix: Clear browser cache, check print settings, try different browser

Issue: Database migration failed
Fix: Run one statement at a time, check SQLite version
